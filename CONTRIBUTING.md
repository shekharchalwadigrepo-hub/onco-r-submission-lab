# Contributing

This lab is educational. Contributions should stay accurate to public FDA,
CDISC, and R Consortium sources, and should not present templates as
validated production programs.

- Prefer primary sources (FDA Study Data Technical Conformance Guide, CDISC
  IG, R Consortium pilot repositories) over blog paraphrases.
- Label every code sample as a teaching template.
- Do not add real or disguised patient-level data.
- Keep the app runnable with only shiny, bslib, and DT.
